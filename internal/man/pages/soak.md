# Release soak status

## Synopsis

Show the release soak state, what is missing, and the exact next actions.

## Usage

`sila soak [--json|--toon]`

## Examples

```sh
sila soak
sila soak --json
```

## See Also

- `sila man` lists every topic in this section.
- `sila release status` shows the full preflight view.
