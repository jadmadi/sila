Sila v0.18.0 · The Continuity Release

One thread across every agent.

Sila is a local-first continuity engine for AI coding agents. It reads the session stores you already have, grounds claims against the files they cite, and serves memory, handoffs, goals, and gates through a CLI and a native MCP server. No cloud account. No telemetry. No CGO.

Quickstart

curl -fsSL https://raw.githubusercontent.com/jadmadi/sila/main/install.sh | sh

Principle

Logs record claims; code is truth. A claim that quotes a real file is still a claim. Sila surfaces grounding and staleness instead of presenting raw session text as verified architecture.
